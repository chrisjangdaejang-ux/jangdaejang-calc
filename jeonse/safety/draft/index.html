전셋집 안전 진단
시안 화면이에요. 실거래 시세·공시가격·건축물대장 자동 조회는 아직 연결 전이라, 지금은 값을 직접 넣거나 '예시 값 넣기'로 화면 모양만 볼 수 있어요. '예시 값'은 화면 확인용 가상의 숫자이고 실제 집 정보가 아니에요.

이 전셋집, 계약해도 될까요?

계약하기 전에 주소와 보증금을 넣어 보세요. 집예보는 국토교통부 실거래·건축물대장, 공시가격, 주택도시보증공사(HUG) 보증 기준 같은 공식 공공 자료로 내 보증금이 집값에 비해 얼마나 높은지, 보증보험에 가입할 수 있는 금액인지, 건물이 주거용인지를 쉬운 말로 보여 드려요. 무료예요.

1. 집 주소와 계약 조건

주소를 넣으면 같은 건물·같은 크기의 실거래, 공시가격, 건축물대장을 자동으로 찾아요(연결 예정).

반전세(보증금 + 월세)면 월세도 넣어요.

등기부 을구의 근저당 채권최고액 + (다가구면) 먼저 들어온 세입자들의 보증금 합계. 집예보가 자동으로 알 수 없는 값이에요.

연결 후: 같은 단지(건물)·같은 크기의 최근 3개월 매매 실거래 가운데값.

부동산 공시가격 알리미 ↗에서 주소로 찾을 수 있어요.

연결 후: 같은 단지(건물)·같은 크기의 최근 3개월 전세 실거래 가운데값.

위반건축물인지 직접 확인

위반건축물 표시는 공개된 자료(오픈API)로 받을 수 없어서 집예보가 자동으로 알려 드리지 못해요. 정부24나 세움터에서 건축물대장을 무료로 열람하면 대장 맨 위 오른쪽에 '위반건축물' 표시가 있는지 바로 볼 수 있어요.

위반건축물은 HUG 전세보증 가입이 거절되거나 전세자금대출이 어려울 수 있어요.

정부24 ↗세움터 ↗체크리스트: 주거용 건물인지

집주인 빚과 권리등기부·세금·선순위 보증금은 공공 자료로 자동 확인이 안 돼요

등기부등본 직접 확인

등기부는 대법원 인터넷등기소에서 누구나 열람할 수 있어요(유료 열람). 계약 직전과 잔금 날에 한 번 더 떼어 보세요.

  • 갑구 맨 아래 소유자가 계약하는 사람과 같은지
  • 갑구에 신탁·압류·가압류·가등기가 있는지
  • 을구의 근저당 채권최고액 — 위 '나보다 앞선 빚' 칸에 넣으면 보증보험 계산에 반영돼요
  • 을구에 임차권등기가 있는지 — 예전 세입자가 보증금을 못 받은 흔적일 수 있어요
인터넷등기소 ↗체크리스트: 갑구·을구신탁

집주인 세금 체납 · 먼저 들어온 세입자 직접 확인

집주인이 밀린 세금과 나보다 먼저 들어온 세입자의 보증금은 내 보증금보다 먼저 돌려받을 수 있어요. 집주인 동의를 받아 납세증명서와 확정일자 부여 현황을 확인하세요.

3. 진단 결과 저장·공유

[결과 카드 자리]
'이 전셋집, 계약 전에 확인한 것' · 전세가율 · 보증보험 가입 기준 · 건물 용도 · 직접 확인할 3가지 · 집예보 주소
공유할 때는 주소·보증금을 빼는 것이 기본(켜면 넣기)

관심 주소를 저장하면 '내 계정'에서 다시 보고, 이 집의 새 실거래·공시가격이 나오면 다시 진단할 수 있어요(연결 예정).

4. 등기부까지 전문가가 봐 드려요

공인중개사 등기부 검토 + 맞춤 특약

[가격 자리 — 대표 결정]

위의 무료 진단이 공공 자료로 볼 수 있는 것을 보여 드린다면, 이 서비스는 등기부등본을 사람이 직접 읽고 이 집 계약서에 넣을 특약을 정리해 드려요. 집예보 운영사 소속 공인중개사가 맡아요.

  1. 진단 결과에서 신청(카카오 간편 로그인)
  2. 공인중개사가 이 주소의 등기부를 열람해 갑구·을구 권리 관계를 확인
  3. 무료 진단 결과 + 등기부 확인 내용을 합쳐 '확인해야 할 점'을 쉬운 말로 정리
  4. 이 집 상황에 맞는 특약 문구 초안 전달(예: 잔금 다음 날까지 근저당 설정 금지, 보증보험 가입 거절 시 계약 해제)
시안 메모(공개 화면에는 넣지 않음): 중개 의뢰 없이 받는 유료 권리 검토·특약 작성이 공인중개사 업무 범위와 변호사법(비변호사의 법률사무 취급 금지)에 맞는지 변호사 확인 필요. 확인 전에는 공개하지 않아요.

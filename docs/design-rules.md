# 집예보 디자인 점검표 (design-rules)

화면을 새로 만들거나 고칠 때, 올리기 전에 이 표를 위에서부터 확인한다.
색·글자 크기·폭의 정확한 값은 `docs/design_guide.md`(배치 가이드)와 `assets/aplus.css`·`assets/layout.css` 의 변수를 따른다. 이 문서는 그 값을 **어떻게 써야 하는지**를 정한 점검표다.

- 만든 날: 2026-11-28 (대표 승인 — 외부 디자인 스킬은 설치하지 않고, 쓸 만한 원칙만 골라 우리 기준으로 다시 썼다)
- 적용 범위: 모든 화면. 단, 4장 '홍보 화면'은 광고·제휴 안내(/ad/), 소개(/about/) 같은 알리는 화면과 홈 첫 화면에만 해당한다. 시세·계산·지도 같은 데이터 화면은 1~3장과 5~8장만 지킨다.

---

## 1. 숫자와 그래프가 먼저 읽혀야 한다

- [ ] 화면마다 가장 중요한 숫자 하나가 제일 먼저 눈에 들어온다(큰 글자 `--fs-num`, 굵게). 그 밑에 기준(기간·면적·기준일)을 작은 글자로 붙인다.
- [ ] 금액·퍼센트·건수가 세로로 늘어서는 표·카드에는 `font-variant-numeric: tabular-nums` 를 준다(자릿수가 줄 맞춰 보이게).
- [ ] 오름 빨강(`--up`)·내림 파랑(`--down`)은 숫자와 ▲▼에만 쓴다. 단추·링크·장식에 쓰지 않는다.
- [ ] 색만으로 뜻을 전하지 않는다. 오름·내림·위험도는 ▲▼·글자(좋음/주의/위험)를 함께 쓴다.
- [ ] 그래프 위에 아무것도 겹치지 않는다: 떠 있는 단추, 광고 칸, 아래 탭, 안내 말풍선, 고정 머리줄이 그래프·축·범례를 가리면 안 된다.
- [ ] 그래프 축 글자는 12.5px 이상, 범례는 그래프 바로 위나 옆에 둔다. 단위(만 원·억 원·%)를 축이나 제목에 꼭 적는다.
- [ ] 출처와 기준일은 숫자 가까이에 작은 글씨(`--fs-xs`)로 적는다.

## 2. 글자 크기와 간격은 정해진 단계만 쓴다

- [ ] 글자 크기는 `--fs-xs`(12.5) · `--fs-sm`(13.5) · `--fs-md`(15) · `--fs-body`(16) · `--fs-lg`(18) · `--fs-xl`(20) · `--fs-2xl`(24+) · `--fs-num`(28) 안에서 고른다. 화면마다 새 크기(14.2px, 17.5px 등)를 만들지 않는다.
- [ ] 한 화면에 쓰는 글자 크기는 5단계 이내로 줄인다. 위계는 크기보다 굵기·색(`--text` → `--sub` → `--sub2`)으로 먼저 만든다.
- [ ] 간격은 4의 배수만: 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64.
  - 카드 안 여백: 휴대폰 16~20px, PC 20~24px
  - 카드 사이: 8~16px
  - 큰 묶음(섹션) 사이: 휴대폰 48px 안팎, PC 64px 안팎
- [ ] 한 줄 길이는 본문 기준 40~45자(약 40em)를 넘지 않게 `max-width` 를 준다. PC에서 긴 글이 화면 끝까지 늘어나지 않게 한다.
- [ ] 줄 간격: 본문 1.6~1.75, 제목 1.3~1.4, 숫자 칸 1.3.
- [ ] 큰 제목은 `text-wrap: balance` 로 줄 끝에 한두 글자만 남지 않게 한다.

## 3. 색은 있는 것만 쓴다

- [ ] 남색 `--blue`(#4338CA)는 누를 수 있는 것(단추·링크·지금 탭)과 제목 속 강조 한 곳에만.
- [ ] 금색(#B8942A 계열)은 모닝 브리핑·프리미엄(유료)·창립 광고주 표시에만.
- [ ] 바탕은 흰색, 칸 구분은 `--gray2` 바탕 또는 `--line` 테두리 하나로. 그림자는 거의 쓰지 않는다.
- [ ] 화면마다 새 색을 만들지 않는다. 새 색이 꼭 필요하면 `design_guide.md` '0. 색' 표에 먼저 올린다.

## 4. 홍보 화면(광고·제휴 안내, 소개, 홈 첫 화면)

- [ ] 첫 화면(휴대폰 390×844) 안에 **누가 무엇을 얻는지 한 문장 + 핵심 약속 + 주된 단추 하나**가 들어온다.
- [ ] 주된 단추(남색 채움)는 한 묶음에 하나. 나머지는 테두리 단추·글자 링크로 낮춘다. 휴대폰에서 단추 두 개가 나란히 있으면 너비를 같게 맞춘다.
- [ ] 긴 소개 글 앞이나 뒤에 '핵심 약속 3~4가지'를 짧은 칸으로 따로 보여 준다. 칸 안의 내용은 이미 페이지에 있는 사실만 다시 쓴다(새 약속·숫자를 지어내지 않는다).
- [ ] 섹션마다 작은 머리글(한국어) → 큰 제목 → 한두 줄 설명 순서로 쓴다. 영어 머리글(WHY·PRODUCTS 같은 것)은 쓰지 않는다. 목차 이름과 섹션 머리글을 같은 말로 맞춘다.
- [ ] 긴 페이지는 섹션 사이에 옅은 줄(`--line2`)과 넉넉한 간격을 둬 어디서 바뀌는지 보이게 한다.
- [ ] 휴대폰 목차·칩 줄이 4줄 넘게 쌓이면 옆으로 넘기는 한 줄로 바꾸고, 오른쪽 끝을 흐리게 해 더 있다는 걸 보여 준다(페이지 전체가 옆으로 밀리면 안 된다).
- [ ] 가격·규칙·'바로 가능/준비 중' 표시·법적 문구는 디자인을 고치면서 절대 바꾸지 않는다.

## 5. 흔한 'AI가 만든 것 같은' 모양 피하기

- [ ] 보라·분홍 그라데이션 바탕, 빛나는 테두리, 유리 효과(흐린 반투명 카드) 쓰지 않는다.
- [ ] 똑같은 크기의 카드 3개를 아이콘+제목+한 줄로 늘어놓는 틀에 기대지 않는다. 가장 중요한 칸 하나를 크게(전체 폭·연한 남색 바탕) 두고 나머지를 작게 둔다.
- [ ] 이모지를 제목·단추 아이콘 대신 쓰지 않는다. 아이콘은 지금 화면들과 같은 굵기의 선 아이콘(SVG)만.
- [ ] '혁신적인', '차원이 다른', '지금 바로 경험해 보세요' 같은 빈 말 대신, 실제로 하는 일과 숫자를 쓴다.
- [ ] 의미 없는 장식(배경 도형, 떠다니는 점, 큰 그림자, 둥근 모서리 과다)을 넣지 않는다. 둥근 모서리는 칸 14~20px, 단추 12~16px, 칩 999px.
- [ ] 가짜 후기·가짜 통계·지어낸 로고를 넣지 않는다. 통계가 없으면 '문의하시면 최신 자료로 안내드려요'처럼 사실대로 쓴다.

## 6. 움직임은 조용하게

- [ ] 움직임은 누를 때·올릴 때의 바탕색·테두리 변화(0.15초 안팎) 정도만. 화면 들어올 때 글자가 날아오거나 튀는 효과는 쓰지 않는다.
- [ ] 숫자가 0부터 올라가는 효과는 쓰지 않는다(숫자를 바로 읽을 수 있어야 한다).
- [ ] 부드러운 스크롤·전환은 `@media (prefers-reduced-motion: no-preference)` 안에서만 켜고, `reduce` 일 때는 끈다.
- [ ] 광고·늦게 오는 자료가 나타나도 화면이 밀리지 않게 자리 높이를 미리 잡는다.

## 7. 화면 크기별 확인 (올리기 전 꼭)

Playwright로 아래 두 크기 스크린숏을 찍어 눈으로 본다. 1024·360도 가능하면 함께.

| 크기 | 기기 | 확인할 것 |
|---|---|---|
| 390 × 844 | 휴대폰(기준) | 첫 화면에 결론·주된 단추가 보이는지, 단추·칩 글자 줄바꿈, 아래 탭이 내용을 가리지 않는지 |
| 1280 × 800 | PC(기준) | 글 줄 길이, 두 칸 배치, 오른쪽 요약 칸이 그래프를 가리지 않는지, 빈 공간이 한쪽에 몰리지 않는지 |

- [ ] 옆으로 넘침 없음: `document.documentElement.scrollWidth - innerWidth` 가 0. (표·칩 줄은 그 안에서만 옆으로 넘긴다)
- [ ] 그래프·핵심 숫자를 가리는 것 없음(고정 머리줄, 아래 탭, 떠 있는 단추, 광고).
- [ ] 누를 수 있는 것은 높이 44px 이상, 글자 13px 이상.
- [ ] 키보드로 이동할 때 초점 테두리가 보인다(`:focus-visible`).
- [ ] 글자와 바탕 대비가 충분하다(본문 4.5:1 이상). 연한 회색 글씨에 연한 바탕을 겹치지 않는다.

## 8. 문구

- [ ] 서비스 이름은 화면에서 **집예보**로 쓴다(바뀌면 새 이름). 회사명은 약관·사업자 정보처럼 법적으로 필요한 곳에만.
- [ ] 다른 부동산 앱·업체 이름은 쓰지 않는다(그쪽 홍보가 될 수 있다). `tools/rival-name-test.js` 가 확인한다.
- [ ] 말투는 쉽고 단정한 ~요체: "보여 드려요", "확인해 보세요". 반말·명령조·과장 금지.
- [ ] 전문 용어는 부동산을 전혀 모르는 사람도 알도록 풀어 쓴다(예: 커트라인 → 예상 당첨 가점, LTV → 집값 대비 대출 비율).
- [ ] 한 문장에 한 가지만 말한다. 50자를 넘으면 나눠 본다.
- [ ] 숫자는 단위와 기준을 함께: "8.7% 올랐어요(1년 전보다, 전용 84㎡)".

### 올리기 전 짧은 순서

1. 변경한 공용 파일(`assets/*`)의 `?v=` 를 쓰는 곳 모두에서 올린다.
2. `sw.js` 의 캐시 버전(`jdj-vNNN`)을 1 올린다.
3. `tools/*-test.js` 를 모두 돌려 통과를 확인한다.
4. 390×844, 1280×800 스크린숏을 고치기 전·후로 비교한다.

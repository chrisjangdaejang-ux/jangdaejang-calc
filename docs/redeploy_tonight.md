# 오늘 밤 서버 다시 배포하기 (모닝 브리핑 무료 체험 열기)

목적: 모닝 브리핑 **7일 무료 체험**을 오늘 밤부터 받고, 내일 아침 7시대에 첫 브리핑 메일이 가게 하기.
유료 결제는 통신판매업 신고번호가 나올 때까지 **잠긴 채로** 둡니다(코드 맨 위 `PAID_OPEN = false`).

걸리는 시간: 10~15분. 순서대로 한 번에 하시면 됩니다.
⚠️ 표시가 있는 곳만 조심하세요.

---

## 0. 준비 — 새 코드가 올라왔는지 확인

1. 이 주소를 엽니다: https://raw.githubusercontent.com/chrisjangdaejang-ux/jangdaejang-calc/main/tools/agent-backend.gs
2. `Ctrl+F` 를 누르고 `PAID_OPEN` 을 찾습니다.
   - 찾아지면 새 코드입니다. 다음으로 넘어가세요.
   - 안 찾아지면 5분 뒤 `F5`(새로 고침)를 눌러 다시 찾습니다(깃허브가 새 파일을 보여 주는 데 몇 분 걸릴 수 있어요).

## 1. Apps Script 편집기 열기

방법 A(권장): 중개사 제휴 신청이 쌓이는 **구글 시트**를 엽니다 → 위 메뉴 **확장 프로그램** → **Apps Script**.
방법 B: https://script.google.com 에 들어가 **내 프로젝트** 목록에서 그 시트에 붙은 프로젝트를 엽니다.

편집기 왼쪽 **파일** 목록을 봅니다.
- 보통 `코드.gs`(영어 화면이면 `Code.gs`) 하나와 `appsscript.json` 이 있습니다. → `코드.gs` 를 바꿉니다.
- `.gs` 파일이 두 개 이상이면: 각 파일을 눌러 맨 첫 줄을 봅니다. **`장대장 공인중개사 제휴 — 구글 시트 + Apps Script 백엔드`** 로 시작하는 파일 **하나만** 바꿉니다. 다른 `.gs` 파일은 그대로 둡니다.
  (다른 `.gs` 파일 안에 `function doGet` 이나 `function doPost` 가 또 있으면 바꾸지 말고 멈춘 뒤 알려 주세요.)

## 2. 코드 바꿔 넣기

1. 0번에서 연 raw 주소 화면을 누르고 `Ctrl+A`(전체 선택) → `Ctrl+C`(복사).
2. 편집기로 돌아와 1번에서 고른 `코드.gs` 를 누르고, 코드 글자 위를 한 번 누른 뒤 `Ctrl+A` → `Ctrl+V`(붙여넣기).
3. 위쪽 **💾 (프로젝트 저장)** 아이콘을 누릅니다(또는 `Ctrl+S`).
4. 확인: 코드 맨 위 쪽에 `v47 변경 요약` 이, 조금 아래에 `const PAID_OPEN = false;` 가 보이면 맞습니다.
   빨간 오류 줄이 뜨면 여기서 멈추고 화면을 캡처해 보내 주세요.

> ⚠️ 저장하는 순간부터 이미 걸려 있는 자동 실행(트리거)은 새 코드로 돌아갑니다. 정상이고, 되돌릴 일은 없습니다.

## 3. 아침 발송 시계 켜기 — `briefInstall` 한 번 실행 (꼭 필요)

모닝 브리핑 메일은 매일 오전 7시대(늦으면 9시대)에 `briefDaily` 가 보냅니다. 그 시계를 거는 함수가 `briefInstall` 입니다.
여러 번 실행해도 시계가 두 개씩 생기지 않으니(먼저 지우고 다시 겁니다) 안심하고 실행하세요.

1. 편집기 위쪽 **▷ 실행** 버튼 오른쪽의 **함수 고르는 칸**(지금 함수 이름이 적힌 칸)을 누릅니다.
2. 목록에서 **`briefInstall`** 을 고릅니다(목록이 길면 키보드로 `brief` 를 치면 가까이 갑니다).
3. **▷ 실행** 을 누릅니다.
4. 권한 창이 뜹니다(새 기능 때문에 드라이브·외부 연결·메일·트리거 권한을 한 번 더 묻습니다 — 정상).
   1. **승인 필요** 창 → **권한 검토**
   2. 대표님 구글 계정 선택
   3. **Google에서 확인하지 않은 앱** 화면 → 왼쪽 아래 **고급** → 맨 아래 **(프로젝트 이름)(으)로 이동(안전하지 않음)**
      — 직접 만든 스크립트라 이렇게 나오는 것이 정상입니다.
   4. 권한 목록 확인 → **허용**(목록에 체크 칸이 있으면 **모두 선택** 후 **허용**)
5. 아래 **실행 로그** 에 `실행이 완료되었습니다` 가 보이면 끝.
6. 확인: 왼쪽 세로 메뉴의 **트리거**(⏰ 시계 모양)를 누르면 `briefDaily` 가 **두 줄**(오전 7시~8시, 오전 9시~10시) 보여야 합니다.

## 4. 같은 주소로 새 버전 배포하기

1. 오른쪽 위 파란 **배포** 버튼 → **배포 관리**.
2. 왼쪽 목록에서 지금 쓰는 **웹 앱** 배포를 고릅니다(보통 하나뿐).
3. 위쪽 **✏️ (수정)** 연필 아이콘을 누릅니다.
4. **버전** 칸을 눌러 **새 버전** 을 고릅니다.
   - 그 아래 **다음 사용자 인증 정보로 실행**·**액세스 권한이 있는 사용자** 칸은 지금 값 그대로 둡니다(손대지 마세요).
5. 아래 **배포** 를 누릅니다 → 끝나면 **완료**.
6. 웹 앱 주소가 `…/AKfycbyFwqwl…/exec` 로 예전과 같은지 봅니다.

> ⚠️ **새 배포** 메뉴는 누르지 마세요. 새 배포를 만들면 서버 주소가 바뀌어 사이트 전체(로그인·문의·체험)가 예전 서버에 연결된 채로 남습니다.
> 실수로 새 배포를 만들었다면 그냥 두고, 위 1~5번(배포 관리 → ✏️ → 새 버전)을 원래 배포에 다시 하면 됩니다.

## 5. 확인 — 무료 체험 직접 해 보기

1. 휴대폰이나 PC에서 엽니다: https://chrisjangdaejang-ux.github.io/jangdaejang-calc/brief/subscribe/
   (이미 열려 있으면 `F5`.)
2. 카카오 로그인 → **받을 동네** 에서 **서울의 구 하나**를 고르고 **이 동네 넣기** → 받을 이메일 적기 → **[필수] 발송용 연락처 수집·이용에 동의해요** 체크 → **7일 무료로 시작하기**.
3. `무료 체험을 시작했어요(2026-11-22 ~ 2026-11-28). 내일 아침부터 …(으)로 보내 드려요.` 가 나오면 성공.
   - 체험 기간은 오늘을 첫날로 세서 7일(11/22~11/28)이라, 메일은 11/23~11/28 아침에 6번 옵니다.
4. 같은 화면 아래 **체험이 끝난 뒤 계속 받고 싶을 때 고르는 요금제예요** 를 펼치면 버튼이 **유료 이용권은 곧 열려요** 로 잠겨 있어야 합니다.
5. 구글 시트에 **브리핑구독** 탭이 새로 생기고 한 줄(상태 `체험`)이 들어와 있으면 저장도 된 것입니다.
6. 내일 아침 7시~8시(데이터가 늦으면 9시~10시)에 메일함을 확인합니다. 보내는 사람 이름은 `집예보`, 보내는 주소는 대표님 구글 계정입니다.
   안 왔으면: 편집기 왼쪽 **실행**(☰ 목록 모양)에서 `briefDaily` 줄의 상태를 보고, 시트 **발송기록** 탭의 마지막 줄을 캡처해 보내 주세요.

## 오늘 밤 하지 않아도 되는 것 (11/28에 해도 됨)

- `setupAgency`(분양대행 정산 시트·매일 6시 정산), `setupAgentTools`(중개사 고객 관심 단지 매일 8시 알림), `alertsInstall`(관심 단지·청약 알림 메일), `ytKitInstall`(유튜브 키트 월요일 메일) — 체험·브리핑 발송과 상관없습니다. **실행하지 마세요.** 실행하지 않으면 그 자동 메일들은 나가지 않습니다.
- 도메인(zipyebo.com) 바꾸기 — 관계없습니다. 서버의 사이트 주소는 지금 주소 그대로이고, 카카오 로그인은 지금 주소(github.io)를 계속 허용합니다.

## 유료 판매를 여는 날 (통신판매업 신고번호를 받은 뒤)

Claude에게 "유료 판매 열어 줘"라고 하면 화면(assets/config.js)·서버의 `PAID_OPEN` 을 함께 `true` 로 바꾸고 사업자 정보에 신고번호를 넣습니다.
그다음 위 **2번(코드 바꿔 넣기) → 4번(새 버전 배포)** 만 다시 하면 됩니다.

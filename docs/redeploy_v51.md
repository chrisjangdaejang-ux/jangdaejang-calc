# 서버 v51 재배포 — 동네 파트너 후속(숨김 그대로)

이번 재배포로 **화면에 새로 보이는 것은 없어요.** `PARTNER_ENABLED`·`BILLING_OPEN`·`LISTING_TIER_ENABLED` 는 모두 꺼진 채예요.
대표님 계정(모닝 브리핑 운영자 모드)만 미리 볼 수 있어요. 걸리는 시간 5~10분. 따로 실행할 함수는 없어요.

## 1. 새 코드 복사하기

1. 이 주소를 엽니다: https://raw.githubusercontent.com/chrisjangdaejang-ux/jangdaejang-calc/main/tools/agent-backend.gs
2. `Ctrl+F` 를 누르고 `v51 변경 요약` 을 찾습니다. 안 찾아지면 5분 기다렸다가 `F5`(새로 고침)를 누르고 다시 찾습니다.
3. 글자 위를 한 번 누르고 `Ctrl+A`(전체 선택) → `Ctrl+C`(복사).

## 2. Apps Script 에 붙여 넣기

1. 구글 시트를 열고 위 메뉴 **확장 프로그램** → **Apps Script** 를 누릅니다(프로젝트 이름: **제목 없는 프로젝트**).
2. 왼쪽 **파일** 목록에서 **Code.gs** 를 누릅니다.
3. 코드 글자 위를 한 번 누르고 `Ctrl+A` → `Ctrl+V`.
4. 위쪽 **💾 (프로젝트 저장)** 을 누릅니다. 아래에 빨간 오류 줄이 없으면 됩니다.

## 3. 새 버전으로 배포하기

1. 오른쪽 위 파란 **배포** → **배포 관리**.
2. 왼쪽에서 지금 쓰는 **웹 앱** 배포를 고릅니다(지금 버전 17).
3. 위쪽 **✏️**(수정) 연필 단추를 누릅니다.
4. **버전** 칸을 눌러 **새 버전** 을 고릅니다.
5. 아래 **배포** → 창이 바뀌면 **완료**.
6. 권한 창이 뜨면 **권한 검토** → 대표님 구글 계정 → **고급** → **제목 없는 프로젝트(으)로 이동(안전하지 않음)** → **허용**.

> ⚠️ **새 배포** 는 절대 누르지 마세요. 서버 주소가 바뀌어 사이트가 옛 서버에 붙어 있게 돼요. 꼭 **배포 관리 → ✏️ → 버전: 새 버전 → 배포 → 완료** 입니다.

## 4. 확인

1. https://chrisjangdaejang-ux.github.io/jangdaejang-calc/dongne/admin/ 을 엽니다(운영자 모드를 켠 카카오 계정으로 로그인된 PC 브라우저).
2. **지금 상태** 칸의 **설정값 보기** 를 누르면 지금 설정이 보여요.
3. **이 기기에서 미리 보기 켜기** → **신청 화면 미리 보기** 에서 `○월 ○일까지 가입하면 중개사 플러스 포함` 문구가 보이면 끝이에요
   (문 열기 전이라 날짜 대신 `지금 가입하면 중개사 플러스 포함` 이 보일 수 있어요).

## 설정값 바꾸는 법(코드·재배포 없이)

Apps Script 왼쪽 **⚙️ 프로젝트 설정** → 맨 아래 **스크립트 속성** → **스크립트 속성 수정** → **스크립트 속성 추가**
→ 속성 `DP_SETTINGS`, 값에 아래처럼 JSON 한 줄 → **스크립트 속성 저장**. 다음 요청부터 바로 적용돼요.

```
{"PLUS_BUNDLE_MONTHS":3,"SLOTS_PER_DONG":3,"PARTNER_PRICE":9900,"LISTING_PRICE":4900,"LISTING_TIER_ENABLED":false}
```

| 이름 | 뜻 | 기본값 |
|---|---|---|
| `PARTNER_OPEN_DATE` | 문 연 날(비우면 처음 문을 연 날 자동 기록) | 자동 |
| `PLUS_BUNDLE_MONTHS` | 문 연 날부터 몇 달 안 가입하면 중개사 플러스 포함 | 3 |
| `PLUS_BUNDLE_UNTIL` | 포함 마감일을 직접 정할 때(`2027-03-31`). 정하면 위 두 값보다 먼저 | 비움 |
| `SLOTS_PER_DONG` / `SLOTS_BY_DONG` | 동마다 대표 자리 수 / 동별 따로(`{"11680\|대치동":4}`) | 3 / 없음 |
| `PARTNER_PRICE` / `PRICE_BY_DONG` | 대표 파트너 월 요금(연간은 10배) / 동별 따로. 이미 가입한 파트너는 가입 때 값 그대로 | 9,900 / 없음 |
| `LISTING_TIER_ENABLED` / `LISTING_PRICE` | 일반 등록 켜기 / 월 요금(연간 10배, 동 추가 절반) | false / 4,900 |
| `BUNDLE_MODE` / `BUNDLE_PCT` | 중개사 제휴(검색 노출)와 묶음 혜택 `off`·`include`·`discount` / 할인율 | off / 0 |

틀린 이름·값은 무시되고 운영자 화면 **설정값 보기** 에 `받아들이지 않은 설정` 으로 보여요.

# 서버 v50 재배포 — 동네 파트너(숨김) + 자동결제(잠금)

이번 재배포로 바뀌는 것: **아무것도 화면에 보이지 않아요.** 동네 파트너(`DONGNE_ENABLED=false`)와 자동결제(`BILLING_OPEN=false`)는 잠긴 채로 들어가고,
대표님 계정(모닝 브리핑 운영자 모드)만 미리 볼 수 있어요. 걸리는 시간 10분.

## 1. 서버 다시 배포하기 (5분)

1. 이 주소를 엽니다: https://raw.githubusercontent.com/chrisjangdaejang-ux/jangdaejang-calc/main/tools/agent-backend.gs
2. `Ctrl+F` → `v50 변경 요약` 을 찾습니다. 안 찾아지면 5분 뒤 `F5` 를 누르고 다시 찾습니다.
3. 화면을 한 번 누르고 `Ctrl+A` → `Ctrl+C`.
4. 구글 시트 → 위 메뉴 **확장 프로그램** → **Apps Script** → 왼쪽 **파일** 에서 `코드.gs`
   (`.gs` 파일이 여러 개면 첫 줄이 `장대장 공인중개사 제휴 — 구글 시트 + Apps Script 백엔드` 인 파일 하나만).
5. 코드 글자 위를 한 번 누르고 `Ctrl+A` → `Ctrl+V` → 위쪽 **💾 (프로젝트 저장)**.
6. 오른쪽 위 파란 **배포** → **배포 관리** → 왼쪽 **웹 앱** 배포 → 위쪽 **✏️ (수정)** → **버전** 칸 **새 버전** → **배포** → **완료**.
   권한 창이 뜨면 **권한 검토** → 대표님 구글 계정 → **고급** → **(프로젝트 이름)(으)로 이동(안전하지 않음)** → **허용**.

> ⚠️ **새 배포** 는 누르지 마세요(서버 주소가 바뀌어요). 꼭 **배포 관리 → ✏️ (수정) → 새 버전** 입니다.
> 따로 실행할 함수는 없어요. 시트 탭('동네파트너' 등)은 처음 쓸 때 저절로 생겨요.

## 2. (선택) 바로 승인용 공공 자료 키 — `DATA_GO_KR_KEY`

없어도 돼요. 없으면 모든 신청이 '검토 대기'로 가고 운영자 화면에서 [승인]을 누르면 돼요.

1. https://www.data.go.kr/data/15107745/standard.do (전국공인중개사사무소표준데이터) → 로그인 → 파란 **활용신청** → 활용 목적 고르기 → **활용신청**. 자동 승인이에요(반영까지 1~2시간).
2. **마이페이지** → **데이터활용** → **Open API** → **활용신청 현황** → 방금 신청한 줄 → **일반 인증키(Decoding)** 오른쪽 **복사**.
   (수집용으로 이미 쓰는 같은 키예요. 이 자료만 따로 활용신청이 필요해요.)
3. Apps Script 왼쪽 **⚙️ 프로젝트 설정** → 맨 아래 **스크립트 속성** → **스크립트 속성 추가** → 속성 `DATA_GO_KR_KEY`, 값 `Ctrl+V` → **스크립트 속성 저장**.
   키는 Claude 에게 보내지 마세요.

## 3. 미리 보기

1. https://chrisjangdaejang-ux.github.io/jangdaejang-calc/dongne/admin/ 을 PC 에서 엽니다(운영자 모드를 켠 그 카카오 계정으로 로그인된 브라우저).
2. **이 기기에서 미리 보기 켜기** → **신청 화면 미리 보기** / **내 파트너 화면 미리 보기**.

## 나중에(지금 하지 않음)

- 문 열기: `assets/config.js` `PARTNER_ENABLED` + 서버 `DONGNE_ENABLED` 를 함께 `true`.
- 자동결제 열기(토스 빌링 계약 뒤): 서버 `BILLING_OPEN`·`PAID_OPEN`, 화면 `BILLING_OPEN` 을 `true` + 스크립트 속성 `TOSS_BILLING_CLIENT_KEY`(빌링 상점 클라이언트 키),
  빌링 전용 시크릿 키가 따로 나오면 `TOSS_BILLING_SECRET_KEY`.
- 묶음 혜택: `assets/dongne-core.js` 의 `bundleMode`('off'|'include'|'discount')·`bundlePct` — 서버 같은 블록도 함께(시험이 같은지 확인).

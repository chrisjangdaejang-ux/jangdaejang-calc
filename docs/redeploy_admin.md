# 운영자 모드 켜고 여러 지역 모닝 브리핑 받기 (서버 v48)

목적: 대표님 계정만 모닝 브리핑 **받는 지역·관심 단지 수 제한 없이**(지역 300곳·단지 100개까지 — 전국 시·군·구는 약 250곳) 받아 보기.
요금제·결제·유료 잠금(`PAID_OPEN = false`)은 **그대로**입니다. 다른 회원에게는 아무것도 바뀌지 않아요.

걸리는 시간: 15~20분. 1 → 2 → 3 → 4 순서대로 하시면 됩니다. ⚠️ 표시가 있는 곳만 조심하세요.

---

## 1. 서버 다시 배포하기 (5분)

1. 이 주소를 엽니다: https://raw.githubusercontent.com/chrisjangdaejang-ux/jangdaejang-calc/main/tools/agent-backend.gs
2. `Ctrl+F` 를 누르고 `v48 변경 요약` 을 찾습니다. 안 찾아지면 5분 뒤 `F5` 를 누르고 다시 찾습니다.
3. 화면을 한 번 누르고 `Ctrl+A`(전체 선택) → `Ctrl+C`(복사).
4. 구글 시트 → 위 메뉴 **확장 프로그램** → **Apps Script** → 왼쪽 **파일** 에서 `코드.gs` 를 누릅니다.
   (`.gs` 파일이 여러 개면 첫 줄이 `장대장 공인중개사 제휴 — 구글 시트 + Apps Script 백엔드` 인 파일 하나만.)
5. 코드 글자 위를 한 번 누르고 `Ctrl+A` → `Ctrl+V` → 위쪽 **💾 (프로젝트 저장)**.
6. 오른쪽 위 파란 **배포** → **배포 관리** → 왼쪽의 **웹 앱** 배포 고르기 → 위쪽 **✏️ (수정)** → **버전** 칸에서 **새 버전** → **배포** → **완료**.

> ⚠️ **새 배포** 는 누르지 마세요(서버 주소가 바뀌어 사이트가 옛 서버에 붙어 있게 돼요). 꼭 **배포 관리 → ✏️ (수정) → 새 버전** 입니다.
>
> 이번 배포에는 **내 집 성적표·새 알림 종류(v49)** 도 함께 들어가요. 배포가 끝나면 편집기 함수 고르는 칸에서 **`alertsInstall`** 을 골라 **▷ 실행** 을 한 번 눌러 주세요(알림 메일·월요일 성적표 메일 시계를 함께 걸어요 — 자세한 내용 `docs/alerts.md` 6절).

## 2. 엔진 연결 비밀값 넣기 — `BRIEF_PULL_TOKEN` (처음 한 번만, 5분)

지금은 깃허브 쪽 값이 비어 있어서(11/22 실행 기록: `BRIEF_PULL_TOKEN 없음`) 엔진이 구독자 목록을 못 읽어요.
이 값이 없어도 **전국 모든 시·군·구의 구 단위 브리핑은 매일 만들어져요**(이번에 바꿈). 넣으면 구독 동네의 전세·월세까지 매일 새로 받아 더 정확해지고, 커뮤니티 규칙·주간 리포트·유튜브 키트 전달도 함께 켜져요.

깃허브와 Apps Script 두 곳에 **같은 값**이 있어야 해요. 아래 방법은 Apps Script 가 값을 만들어 자기 쪽에 넣어 주므로, 대표님은 **깃허브에 한 번 붙여 넣기만** 하면 됩니다.
값은 Claude 에게 보내지 마세요(Claude 도 묻지 않아요).

### 2-1. Apps Script 에서 값 만들기
1. 1번에서 연 Apps Script 편집기 위쪽 **▷ 실행** 오른쪽의 **함수 고르는 칸**을 누릅니다.
2. 목록에서 **`pullTokenNew`** 를 고릅니다(키보드로 `pull` 을 치면 가까이 가요).
3. **▷ 실행** 을 누릅니다. (권한 창이 뜨면 **권한 검토** → 대표님 구글 계정 → **고급** → **(프로젝트 이름)(으)로 이동(안전하지 않음)** → **허용**.)
4. 아래 **실행 로그** 에 `BRIEF_PULL_TOKEN 새 값(…)` 줄과 그 아래 **영어·숫자 64자리** 한 줄이 나옵니다.
5. ⚠️ 그 64자리**만** 마우스로 드래그해 `Ctrl+C`. 앞뒤 빈칸·다른 글자가 같이 잡히지 않게 하세요.
   (Apps Script 쪽 **⚙️ 프로젝트 설정 → 스크립트 속성** 에는 이미 같은 값이 저장됐어요. 직접 고칠 필요 없어요.)

### 2-2. 깃허브에 붙여 넣기
1. 이 주소를 엽니다: https://github.com/chrisjangdaejang-ux/jangdaejang-timing/settings/secrets/actions
   (직접 찾아가려면: 저장소 `jangdaejang-timing` → 위쪽 **Settings** → 왼쪽 **Secrets and variables** → **Actions**.)
2. **Repository secrets** 목록을 봅니다.
   - `BRIEF_PULL_TOKEN` 이 **없으면**(지금 상태): 초록 **New repository secret** → **Name** 칸에 `BRIEF_PULL_TOKEN` 그대로 → **Secret** 칸에 `Ctrl+V` → **Add secret**.
   - `BRIEF_PULL_TOKEN` 이 **있으면**: 그 줄 오른쪽 **✏️ (연필, Update)** → **Value** 칸을 지우고 `Ctrl+V` → **Update secret**.
3. ⚠️ 이름은 대문자·밑줄까지 정확히 `BRIEF_PULL_TOKEN` 이어야 해요. 다른 저장소(jangdaejang-calc·jangdaejang-engine)가 아니라 **jangdaejang-timing** 입니다.

> ⚠️ 나중에 `pullTokenNew` 를 다시 실행하면 값이 바뀌어요. 그때는 2-2 를 새 값으로 다시 해야 해요(안 하면 엔진이 구독자 목록을 못 읽어요 — 브리핑 발송 자체는 멈추지 않아요).
> 확인: 다음 날 새벽 브리핑 실행 기록에 `구독 동네 N 곳` 이 보이면 맞게 된 거예요. Claude 에게 "브리핑 토큰 됐는지 봐 줘"라고 하시면 실행 기록을 확인해 드려요.

## 3. 운영자 모드 켜기 (3분)

1. PC 에서 이 주소를 엽니다: https://chrisjangdaejang-ux.github.io/jangdaejang-calc/brief/manage/?op=1
   - 로그인이 안 돼 있으면 **카카오 간편 로그인** 을 눌러 무료 체험을 신청한 그 카카오 계정으로 로그인합니다.
2. 화면 맨 아래 **운영자 모드** 칸의 **운영자 모드 켜기** 를 누릅니다.
   → `확인 메일을 보냈어요. …` 가 나옵니다.
3. 서버 주인 구글 계정 메일함(Apps Script 를 만든 구글 계정 — Gmail)을 엽니다. 제목 `[집예보] 모닝 브리핑 운영자 모드 켜기 링크` 메일이 와요.
4. ⚠️ 메일 속 링크를 **30분 안에**, **1번 화면을 연 그 PC 브라우저**에서 엽니다(같은 카카오 계정으로 로그인된 곳이어야 켜져요).
   - 휴대폰에서 열었다면 그 화면의 **카카오 간편 로그인** 으로 같은 카카오 계정에 로그인하면 이어서 켜져요.
5. 화면 위에 `운영자 모드를 켰어요. …` 가 나오고, **받는 지역·관심 단지·청약 정보** 칸에 **운영자: 제한 없음** 이 보이면 끝.

> 링크가 안 되면(`링크가 맞지 않거나 시간이 지났어요`): 1번 주소에서 **운영자 모드 켜기** 를 다시 누르세요(한 시간에 3번까지).
> 끄고 싶을 때: 같은 화면 **운영자 모드** 칸의 **운영자 모드 끄기**.

## 4. 지역 더하기

1. 같은 화면(https://chrisjangdaejang-ux.github.io/jangdaejang-calc/brief/manage/)의 **받는 지역·관심 단지·청약 정보** 칸에서
   - 첫 칸 **시·도**(예: 부산광역시) → 둘째 칸 **시·군·구**(예: 해운대구) → 셋째 칸은 **구 전체** 그대로 → **이 지역 넣기**.
   - 넣을 지역마다 반복합니다(예: 대구 수성구, 대전 유성구, 광주 서구(목록에서는 `전남광주통합특별시` 안에 있어요), 인천 연수구, 울산 남구, 세종시, 경기 성남시 분당구 …).
2. 다 넣었으면 **저장하기**. `내일 아침 브리핑부터 바뀐 지역으로 보내 드려요.` 가 나오면 끝.
3. 오늘 브리핑을 바로 보고 싶으면 https://chrisjangdaejang-ux.github.io/jangdaejang-calc/brief/ 아래 **먼저 내 동네 오늘 브리핑 보기** 에서 시·도 → 시·군·구 → **오늘 브리핑 보기**.
   (전국 시·군·구 브리핑은 이번 변경 뒤 첫 새벽 실행부터 생겨요. 그 전에는 서울 25개 구만 있어요.)

메일은 다음 날 오전 7시대에 와요. 지역이 많으면 **20곳씩 나눠 여러 통**(`운영자 모드 · 3통 중 1번째 메일`)으로 오고, 다른 구독자에게 먼저 보낸 뒤 마지막에 보내요.
시간이나 하루 메일 한도가 모자라면 남은 통은 오전 9시대에 이어서 와요.

## ⚠️ 무료 체험 기간

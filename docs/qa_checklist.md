# 화면 점검 체크리스트 (QA)

대표가 화면을 하나하나 눌러 보지 않아도 되게, 모든 화면과 사람이 실제로 누르는 순서(여정)를 자동으로 점검한다.

## 규칙

- **새 기능을 만들면 여정 점검을 꼭 하나 더한다.** `tools/e2e/run.js` 의 `JOURNEYS` 에 "사람이 누르는 순서 → 보여야 하는 것"을 적는다.
  새 화면이면 `PAGES` 목록에도 주소를 넣는다. 서버가 필요한 기능은 `tools/e2e/lib.js` 의 가짜 서버(makeMock) 응답을 더한다.
- 올리기 전에 직접 돌려 본다: `node tools/e2e/run.js </dev/null` (일부만: `--only=mine,login`, 화면 한 장씩만: `--only=pages`).
  계산·문구 검사(`tools/*-test.js`)와 함께 `node tools/e2e/ci.js </dev/null` 로 한 번에 돌릴 수 있다.
- 자동 실행: jangdaejang-timing 의 `.github/workflows/site_qa.yml` 이 매일 04:47 KST 와, 사이트 저장소에 새 커밋이 생길 때마다(매시 17분에 확인) 돌린다.
  결과는 `data/source_status/site_qa.json` → 감시(watchdog)가 그날 기록(`data/schedule_health.json` 의 `sources.problems`)에 넣어
  **대표 09:07 보고 줄에 실패가 보인다.** 자세한 목록과 화면 사진은 그 실행의 Artifacts(site-qa).
- 점검이 빨간색이면 그날 안에 고친다. 일부러 예외로 두는 것(예: 문장 속 용어 풀이 단추)은 `run.js` 의 `SMALL_OK`·`LEGAL` 처럼 이유를 적고 좁게 연다.

## 화면마다 자동으로 보는 것 (휴대폰 390×844 · PC 1280×800)

| 항목 | 기준 |
|---|---|
| 콘솔·스크립트 오류 | 0건. 우리 사이트 파일 404 도 0건 |
| 가로 스크롤(휴대폰) | 화면 폭보다 넓어지지 않음 |
| 삐져나온 칸·겹침 | 화면 오른쪽 밖으로 나간 칸 없음 |
| 잘린 글자 | 넘침을 숨기는 칸이면 말줄임(…)이 있어야 함 |
| 누르는 칸 크기 | 단추·탭·칩·선택 칸은 높이 44px 이상 (문장 속 글자 링크·용어 풀이·지도 핀은 제외) |
| 깨진 링크 | 사이트 안 링크는 실제 파일이 있어야 함 |
| 보이면 안 되는 글 | undefined·NaN·null·[object Object], TODO·test·테스트용, 영어 오류(Error·failed·HTTP 500·unknown…) |
| 말투 | 화면 문구는 ~요. ~습니다는 약관·개인정보·환불 문서만 |
| 보장 표현 | "수익 보장", "무조건 오릅니다" 같은 단정 금지("보장하지 않아요"는 괜찮음) |
| 경쟁 회사 이름 | 다른 부동산 앱·회사 이름 금지(그쪽 홍보가 됨) |

## 여정 (사람이 누르는 순서)

| 여정 | 확인하는 것 |
|---|---|
| ask (첫 화면 물어보기) | 한 글자·없는 이름이면 단추 가까이 안내, 두 단지 비교 화면으로 이동, 숫자에 NaN 없음 |
| mine (내 집 등록) | 이름으로 찾기 → 시세 → 매수가 단위 안내(15 → "만원 단위로") → [내 집으로 저장] 단추 옆 반응 → 다시 열어도 남음 |
| tabs (빌라·오피스텔·상가) | 시·도 → 시·군·구 → 동 → 건물 순서로 고르면 시세가 나옴 |
| map (지도) | 이름 찾기 → 카드(이름·최근 시세) → 닫기(×) → 없는 이름 안내 |
| consistency (숫자 일치) | 같은 단지(헬리오시티 84㎡대) 최근 시세가 지도 카드와 내 집 시세에서 같음 |
| rank (순위) | 탭을 누르면 목록이 바뀜 |
| calculators (대출·세금·청약) | 빈칸이면 할 일 안내("을(를)" 표기 없이), 채우면 숫자(NaN 없음), 빈칸 제출은 단추 가까이 안내 |
| jeonse (전월세) | 집 종류 탭, 체크리스트 체크가 다시 열어도 남음 |
| login (로그인·구독 관리·알림·구독 신청) | 카카오 로그인 → 돌아와 로그인 상태 저장 → 구독 관리(받는 지역) [저장하기] 반응 → 서버가 영어 코드를 줘도·인터넷이 끊겨도 한글 안내 → 알림 센터 메일 신청 칸 → 구독 신청에서 무료 체험이 유료보다 먼저 |
| alerts (빈 화면 안내) | 알림 센터·성적표·관심 목록이 비었을 때 다음에 할 일 안내 |
| forms (광고 문의·중개사 제휴·파트너) | 빈칸으로 보내면 단추 가까이 안내 |

## 사람이 눈으로 볼 것 (자동으로 잡기 어려운 것)

- 단추 이름이 안내 문장과 같은지(안내에 [저장하기]라고 썼으면 단추도 "저장하기")
- 유료보다 무료 체험이 먼저, 결제 전 금액·기간·자동 결제 여부가 분명한지
- 날짜(기준일)·단위(만원·억·㎡·평)가 숫자 옆에 있는지
- 뒤로 가기·닫기가 있는지, 오류가 나도 입력한 값이 지워지지 않는지

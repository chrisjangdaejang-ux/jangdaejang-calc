# 프리미엄 리포트 결제(토스페이먼츠) 설정 안내 — 운영자용

사이트 쪽 결제 화면은 이미 올라가 있습니다. 운영자가 할 일은 **서버(Apps Script) 코드 교체**와 **비밀 키 넣기** 두 가지입니다.
이 문서에는 비밀 값을 적지 않습니다.

## 1. 서버 코드 바꾸기 (v10 → v11)
1. 구글 시트 '장대장 중개사 제휴'를 엽니다 → 메뉴 **확장 프로그램 → Apps Script**.
2. 왼쪽 `Code.gs`(코드 파일)의 내용을 모두 지우고, 저장소의 `tools/agent-backend.gs` 내용을 통째로 붙여 넣은 뒤 **저장**(디스크 아이콘).
3. 오른쪽 위 **배포 → 배포 관리** → 지금 쓰는 웹 앱 배포의 **연필(편집)** 아이콘 →
   **버전: 새 버전** 선택 → **배포**.
   - 반드시 "기존 배포 편집"으로 하세요. "새 배포"를 만들면 주소가 바뀌어 사이트가 서버를 찾지 못합니다.
   - 권한 허용 창이 뜨면 허용합니다(외부 서비스 접속 = 토스 승인 API, 메일 보내기 = 환불 요청 알림).

## 2. 토스 시크릿 키 넣기 (스크립트 속성)
1. Apps Script 왼쪽 **톱니바퀴(프로젝트 설정)** → 맨 아래 **스크립트 속성** → **스크립트 속성 추가**.
2. 속성 이름: `TOSS_SECRET_KEY`
   값: 지금(심사·테스트 단계)은 토스 공식 문서에 공개된 **문서용 테스트 시크릿 키**를 넣습니다.
   실제 결제를 시작할 때는 토스페이먼츠 상점관리자 → 개발 정보 → API 키에서 받은 **라이브 시크릿 키**로 바꿉니다.
3. **스크립트 속성 저장**. (코드나 깃허브에는 시크릿 키를 절대 넣지 마세요.)
4. `ORDER_SALT` 라는 속성이 첫 주문 때 자동으로 생깁니다. 지우거나 바꾸지 마세요(바꾸면 '다시 보기' 연락처 확인이 안 됩니다).

## 3. '주문' 탭
- 따로 만들 필요 없습니다. **첫 주문(결제하기 버튼) 때 자동으로 생깁니다.**
- 열: 주문번호 · 생성시각 · 상품 · 단지키 · 단지명 · 금액 · 상태 · 연락처(가린 값) · 연락처확인값(해시) · 결제키 · 결제수단 ·
  승인시각 · 열람토큰(해시) · 최초열람시각 · 최근열람시각 · 열람횟수 · 환불상태 · 환불요청시각 · 환불사유 · 메모
- 상태: 결제대기(결제창만 열고 끝냄) / 결제완료 / 승인실패 / 금액불일치 / 입금대기(가상계좌)
- **최초열람시각**이 비어 있으면 아직 리포트를 열지 않은 것 = 7일 이내 전액 환불 대상입니다.
- 연락처 원문은 저장하지 않습니다(010-****-1234, ab***@메일 형태). 고객 연락처 원문이 필요하면 토스페이먼츠 상점관리자의 결제 내역에서 확인합니다.

## 4. 환불 처리 (자동 환불 없음)
1. 고객이 리포트 화면에서 [환불 요청하기]를 누르면 시트 주인 메일로 "[장대장 결제] 환불 요청 주문번호"가 옵니다.
2. 토스페이먼츠 **상점관리자 → 결제 내역**에서 주문번호로 찾아 **결제 취소**.
3. '주문' 시트의 환불상태 칸을 **환불완료**로 바꿉니다. (약속: 영업일 3일 이내)
- 환불상태가 "전액 환불 대상"이면 열람 전·7일 이내 요청이고, "검토 필요"면 열람 후 또는 7일 경과 요청입니다(시스템 오류·내용 불일치면 환불).

## 5. 가격을 바꿀 때
두 곳을 똑같이 고칩니다. ① `tools/agent-backend.gs` 의 `PRICE`(서버 기준, 실제 결제 금액) → 1번 방법으로 재배포
② `assets/pay.js` 의 `PRODUCTS`(화면 표시) 와 `premium/index.html` 가격 문구.

## 6. 심사 후 실제 결제로 바꾸기
1. 토스페이먼츠 상점관리자에서 **결제위젯 연동 키**(라이브)를 확인합니다.
2. `assets/pay.js` 맨 위: `CLIENT_KEY` 를 라이브 클라이언트 키(`live_gck_…`)로, `TEST_MODE` 를 `false` 로(테스트 배지 꺼짐).
3. Apps Script 스크립트 속성 `TOSS_SECRET_KEY` 를 라이브 시크릿 키로 교체(재배포 필요 없음).
4. 상점관리자의 결제위젯 설정에서 결제 수단을 고릅니다. 가상계좌는 입금 알림(웹훅)을 아직 연결하지 않았으므로 **끄는 것을 권장**합니다.
5. 소액(9,900원)으로 실제 결제 → 리포트 열람 전 환불 요청 → 상점관리자에서 취소까지 한 번 해 봅니다.

## 7. 확인 방법
- 저장소에서 `node tools/pay-test.js` 를 실행하면 서버 로직(금액 대조·토큰·열람 기록·환불 요청·다시 보기)을 가짜 시트로 검사합니다.
